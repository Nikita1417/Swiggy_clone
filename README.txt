SWIGGY-INSPIRED FOOD WEBSITE

Files:
- index.html: webpage structure
- style.css: styling and responsive layout
- assets/: the photos you uploaded, used in the page

How to run:
1. Extract the ZIP.
2. Keep index.html, style.css and the assets folder together.
3. Open index.html in Chrome, Edge, Firefox or another browser.

This is a front-end HTML/CSS landing page. The navigation links scroll to page sections; sign-in and ordering are visual demo links and are not connected to a real ordering service.
